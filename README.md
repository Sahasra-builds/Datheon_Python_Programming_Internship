
# Datheon Python Programming Internship

## About
This repository contains three Python projects completed as part of the Datheon Python Programming Internship.

## Completed Tasks

### Task 1 - Hangman Word Guessing Game
- A console-based word guessing game.
- Uses random words.
- Allows limited attempts.
- Checks correct and incorrect guesses.

### Task 3 - Automated File Organizer
- Organizes files based on file extensions.
- Creates separate folders for different file types.
- Avoids overwriting files with duplicate names.

### Task 4 - Interactive Terminal Assistant
- A simple rule-based chatbot.
- Responds to greetings.
- Displays current date and time.
- Performs basic calculations.
- Supports an exit command.

## Technologies Used
- Python 3
- VS Code

## How to Run

Open the terminal inside each task folder and run:

### Task 1
```bash
python hangman.py
```

### Task 3
```bash
python file_organizer.py
```

### Task 4
```bash
python chatbot.py
```
